Sincronizar ventas y pagos desde la API

        

          Reemplaza la subida manual del reporte de ventas para un rango de fechas. Sincroniza ventas
          y luego pagos (conviene en ese orden: la sede de cada pago se infiere de la venta ya
          importada). Usa rangos cortos (un día o pocos días) — rangos muy grandes pueden tardar
          demasiado y fallar por el límite de ejecución de Apps Script (6 minutos).
        

        

          
          
          
        

        

      

    


    

      
Ventas pendientes de sede

      

        Fudo no tiene un campo de sede/sucursal — se infiere por la sala de la mesa (o la referencia
        que haya disponible). Estas ventas no calzaron con ninguna sala/caja/identificador conocido.
        Asigna la sede una vez por grupo: el sistema recuerda la regla para que las próximas ventas
        con esa misma referencia se identifiquen solas.

        Punto de partida real: sube el export "Control de Stock" de FUDO (pestañas Productos e
        Ingredientes) para que Conciliación sepa el stock de una bebida aunque no se haya vendido
        nada ese día. Subir un archivo más reciente reemplaza el punto de partida anterior de cada
        producto — no se acumulan snapshots viejos.
